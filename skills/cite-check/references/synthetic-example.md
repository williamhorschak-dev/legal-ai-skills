# Completed synthetic citation check

This example uses an invented rule and document, not Wisconsin authority.

**Request:** Check the quotation and proposition against the supplied page. No
browser, citator, file archive, or Python execution is available.

**Draft:** Fictional Workshop Rule 4 says, "A signed request may be accepted."
Therefore every signed request must be accepted.

**Supplied page:** Fictional Workshop Rule 4: "A signed request may be accepted."
This rule governs only the fictional workshop exercise.

**Completed response:** The quotation matches the supplied text. The proposition
does not: permission to accept does not, by itself, establish a duty to accept
every request. A supported replacement is: "The supplied rule permits acceptance
of a signed request." The page's authenticity, completeness, operative version,
and treatment remain unverified. No independent retrieval, archive, or citator
check was performed. This limited comparison does not establish filing readiness.

The quote match and proposition review are separate checks. A real evidence run
would record each citation use and its actual source rather than copying this
example's result.
